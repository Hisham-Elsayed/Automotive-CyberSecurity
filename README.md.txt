# Automotive Cybersecurity Course

This repository contains my hands-on labs, notes, and exercises completed during the **Automotive Cybersecurity Course** provided by **Learn In Depth**.

The purpose of this repository is to document my learning journey and provide practical examples of automotive cybersecurity concepts, including cryptography, AUTOSAR security, and secure vehicle communication.

## Course Overview

The course covers the following topics:

### Module 1 – Introduction to Automotive Cybersecurity
- Importance of cybersecurity in modern vehicles
- Common types of cyberattacks
- Cybersecurity vs. Functional Safety

### Module 2 – Cryptographic Algorithms
- Symmetric and asymmetric encryption/decryption
- Hash and MAC generation/verification
- Digital certificates and certificate handling

### Module 3 – Cybersecurity in AUTOSAR
- AUTOSAR Crypto Stack
- CSM, CryIf, and Crypto Driver modules
- Software-based vs. hardware-based cryptographic drivers
- HSM (Hardware Security Module) and SHE (Secure Hardware Extension)

### Module 4 – Securing Vehicle Modules
- Secure Onboard Communication
- Secure Storage
- Secure Diagnostics
- Secure Flashing
- Secure Boot
