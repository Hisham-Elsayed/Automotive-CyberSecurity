========================================
Lab 7 – Hash-Based Message Authentication Code (HMAC)
========================================

Objective
---------
Demonstrate how to verify message integrity and message authenticity using the HMAC algorithm with the SHA-512 hash function.

--------------------------------------------------
Step 1 – Generate a Secret Key
--------------------------------------------------

Generate a random 32-byte secret key that will be shared between the transmitter (Tx) and receiver (Rx).

Command:

openssl rand -out "C:\Hisham\Automotive CyberSecurity\Repo\Lab7_Hash-based_Message_Authentication_code_HMA\Tx\key.bin" 32

Output:
- key.bin (32-byte secret key)

--------------------------------------------------
Step 2 – Generate the HMAC at the Transmitter
--------------------------------------------------

Use the shared secret key to calculate the HMAC of the transmitted message using the SHA-512 algorithm.

Command:

openssl dgst -sha512 -hmac "C:\Hisham\Automotive CyberSecurity\Repo\Lab7_Hash-based_Message_Authentication_code_HMA\Tx\key.bin" "C:\Hisham\Automotive CyberSecurity\Repo\Lab7_Hash-based_Message_Authentication_code_HMA\Tx\message.txt" > "C:\Hisham\Automotive CyberSecurity\Repo\Lab7_Hash-based_Message_Authentication_code_HMA\Rx\enc_digest.txt"

Input:
- Secret key (key.bin)
- Original message (message.txt)

Output:
- enc_digest.txt containing the generated HMAC.

--------------------------------------------------
Step 3 – Recalculate the HMAC at the Receiver
--------------------------------------------------

Using the received message and the same shared secret key, generate a new HMAC.

Command:

openssl dgst -sha512 -hmac "C:\Hisham\Automotive CyberSecurity\Repo\Lab7_Hash-based_Message_Authentication_code_HMA\Tx\key.bin" "C:\Hisham\Automotive CyberSecurity\Repo\Lab7_Hash-based_Message_Authentication_code_HMA\Rx\message.txt" > "C:\Hisham\Automotive CyberSecurity\Repo\Lab7_Hash-based_Message_Authentication_code_HMA\Rx\enc_digestRX.txt"

Input:
- Shared secret key (key.bin)
- Received message (message.txt)

Output:
- enc_digestRX.txt containing the receiver-generated HMAC.

--------------------------------------------------
Step 4 – Verify Message Integrity and Authenticity
--------------------------------------------------

Compare the HMAC generated by the transmitter with the HMAC generated by the receiver.

If both HMAC values are identical:
- The message has not been modified during transmission (Integrity verified).
- The message originated from someone possessing the shared secret key (Authenticity verified).

If the HMAC values are different:
- The message has been altered, corrupted, or generated without the correct secret key.
- Integrity and authenticity verification fail.
